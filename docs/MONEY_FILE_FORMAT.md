# The Microsoft Money Data File Format

The format, and the reader that implements it, is documented in Honey Ledger:
see [honey-ledger: docs/MONEY_FILE_FORMAT.md](https://github.com/James-HoneyBadger/honey-ledger/blob/main/docs/MONEY_FILE_FORMAT.md).

HB SunRise reads the same format with its own copy of the reader in
[`pkg/converters/msmoney/msisam`](../pkg/converters/msmoney/msisam).
